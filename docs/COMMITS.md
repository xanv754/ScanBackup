# Reglas para realizar commits
Estas reglas serán aplicadas para todas las sesiones que se trabajen. Sin excepción:

- Para realizar los commits (cuando se ordene) siempre seguir las convenciones de commits (Conventional commits).
- No agregues información innecesaria a los mensajes (e.g nombre de autor al final de la descripción, detalles específicos menores, etc...). 
- No hagas push después del commit.
- Realiza todos los commits en inglés.
- Separar los commits cuando se tenga sentido y sea funcional regresar de una versión a otra.
